## Complete equations with two remaining ghost fields

Use the scalar matrix $B$ and ghost matrix $A$ in the [chart coordinates](../README.md#the-chart-at-a-nonzero-rank-one-scalar). The ideal generated by the fields $f,g$ and all their Taylor coefficients is stable since $Q_0 f=3af$ and $Q_0g=-3ag$. In its quotient,

$$
A=a\operatorname{diag}(1,1,-2)+dB,\qquad
Q_0p=Q_0q=Q_0a=Q_0d=0,\qquad Q_0u=3au,\qquad Q_0r=-3ar .
$$

Every input word contains seven $B$ coefficients and four $A$ coefficients. The highest possible ordinary polynomial degree is $7+2\cdot4=15$. Setting $d=0$ reduces it to $7+4=11$. The jets of $p,q,d$ are closed spectators. For each spectator monomial, expanding the two displayed variations gives a finite rational linear system.

|---|---:|---:|---:|---:|---:|---:|
| $d,f,g$ | 32 | 331201 | 702 | 50 | 556 | 0 |
| $d,f,g$ | 34 | 517468 | 2257 | 71 | 1446 | 0 |
| $f,g$ | 32 | 331201 | 6119 | 914 | 4828 | 0 |
| $f,g$ | 34 | 517468 | 19523 | 1867 | 12190 | 0 |

With $d$ present the level-32 image has $78+1782+2766+1267+222+4$ terms in degrees eight through thirteen. At level 34 the counts are $264+5385+9269+3933+664+8$. Degrees fourteen and fifteen vanish in both expansions. These complete quotient identities leave the unrestricted first obstruction open. ## Replay

Run from the repository root with Python 3.10 or later. The complete coefficient checks use the standard library.

```sh
d=algorithms/dual_singlets_20261118
p="$d/taylor_hooks/su3_scalar_levi/subregular"
for j in 32 34; do
  python3 "$d/su3_subregular_correction.py" --degree 9 --image "$p/j${j}_through9.json.gz" --initial "$p/j${j}_degree8_primitive.json.gz" --recipe "$p/normal/j${j}_degree9_primitive.json.gz" --out "/tmp/j${j}-degree9.json"
  cmp "/tmp/j${j}-degree9.json" "$p/normal/j${j}_degree9.json" || exit 1
  for v in dfg fg; do
    if [ "$v" = dfg ]; then name=diagonal; check=diagonal; else name=two_ghosts; check=two_ghosts_check; fi
    python3 "$d/su3_subregular_abelian.py" --level "$j" --vanish "$v" --image "$p/normal/j${j}_${name}_image.json.gz" --primitive "$p/normal/j${j}_${name}_primitive.json.gz" --out "/tmp/j${j}-${v}.json"
    cmp "/tmp/j${j}-${v}.json" "$p/normal/j${j}_${check}.json" || exit 1
  done
done
```

Adding `--build --workers 4` to the quotient replay, with temporary image and primitive paths, reconstructs the expansions from the original trace archives. The full-chart level-34 calculation is reproduced by running `su3_subregular_shards.py --level 34 --degree 11 --chunk 1500 --workers 4 --work /tmp/su3-rank-one-34` from the algorithm directory.
