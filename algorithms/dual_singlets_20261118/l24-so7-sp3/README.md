# N=4 SYM：一个完整 L24 物理块的全阶微扰对照

**结论。** 对物理量子数 $(E;R_1,R_2,R_3;J_L,J_R)=(11;5,2,2;1,0)$，$SO(7)$ 与 $Sp(3)$ 的形式微扰 $Q$ 上同调维数均为 **150**。两边在不同喷注切片各多一个类，不能拿单个切片作 S 对偶谱差。结果不证明该块在精确有限耦合下也是 150，也不排除两端都有非微扰 lifting。

| 中央切片 $(\theta_1,\theta_2,\theta_3;n_+,n_-)_Y$ | $SO(7)$ $H(Q_0)$ → 全阶 | $Sp(3)$ $H(Q_0)$ → 全阶 |
|---|---:|---:|
| $(6,3,3;0,0)_{10}$ | 21 → 21 | 20 → 20 |
| $(5,2,2;1,1)_9$ | 0 → 0 | 1 → 1 |
| $(4,1,1;2,2)_8$ | 130 → 129 | 129 → 129 |
| $(3,0,0;3,3)_7$ | 0 → 0 | 0 → 0 |
| 合计 | 151 → **150** | 150 → **150** |

这里 $Y$ 是迹字母数。$\theta_i,n_\pm$ 是 Taylor jet 多重次数。表中全阶指按喷注次数分级的 $E_\infty$；有限过滤的各切片之和给出 $\mathbb Q((u))$ 上的形式上同调维数，$u$ 是微扰参数。它们不是独立的精确物理量子数。

## 怎样把问题变成小矩阵

设 $U$ 是只施加带符号循环与反射等普适关系的多迹复形，$F_G$ 是有限维颜色群 $G$ 的真实迹复形，$I_G=\ker(U\to F_G)$ 是有限秩迹恒等式。固定 $\theta_i,n_\pm$ 时，$Q_0$ 将 $Y$ 提高 1，并保留多重次数。$I_G$ 是子复形，因为作用于一个恒等为零的协变迹多项式，仍得到恒等为零的多项式。奇数 $Y$ 的稳定上同调为零：稳定迹上同调由偶长度的单迹引力子生成元的乘积张成。[Kibe–van Leuven–Mathieson，§2.2 与 Remark 3](https://arxiv.org/html/2610.22332v3)。

对稳定偶 $Y$ 的上同调，在至少 $Y/2$ 个 Cartan 槽上的限制是忠实的。每个生成元是带符号对称化之迹；对 jet 作线性导数与对称化交换。因此 Cartan 上的单槽超多项式确定相应的普适对称化迹。一个 $m$ 因子乘积限制到 $m$ 个不同槽的系数是原来的带符号极化张量，乘上 $2^m m!$；槽碰撞只出现在更低支撑。对槽数降归纳得到忠实性。这里不能把稳定 Cartan 换成有限理论的秩三 Cartan。

于是对于奇数 $Y$：
\[
H^Y(F_G)\simeq
\frac{I^{Y+1}_G\cap \operatorname{im}(Q_0:U^Y\to U^{Y+1})}
{Q_0 I_G^Y}.
\]
分子可用 $J=(Q_0,\rho_{\rm stable})$ 在恒等式空间的核来计算。原始系数子式模素数非零只用来证明有理秩**下界**；上界来自恒等式空间的精确维数、幂零性、普适像秩和稳定 Cartan 检测，不靠有限域秩亏来推断有理秩。

## 逐块核验

**无喷注。** $Sp(3)$ 在 $Y=9$ 的相邻原始秩下界为 712 和 1149，恰好等于中间维数 1861，故 $H^9=0$；中央 $Y=10$ 的核维数 1169，减去入射秩 1149 得 20。$SO(7)$ 中普适 $Y9\to10$ 秩为 1252，构造了其中 101 个独立正交迹恒等式方向，故有限维秩至多 1151，与原始下界相同；中央核 1172，得到 21。21 个方向都由闭乘积张成，其中一个 Cartan 像严格为零；原始增广秩 1152 证明这一个不是有理边界，而不只是模素数非边界。此切片没有正阶入射微分。闭乘积具有带标记乘法给出的全阶形式完备。[Li–Liu–Chang，Thm. 9.1](https://arxiv.org/pdf/2611.24160#page=86)。

**一喷注。** 普适 $H^{10}(U)$ 维数 68，秩三 Cartan 像秩 33。$Sp(3)$ 的 $I^8,I^9,I^{10},I^{11}$ 维数分别为 157、466、495、149。$dI^8$ 的精确秩为 156，给出 $dI^9\le310$；原始小行列式达到 310。在 $I^{10}$ 上 $J$ 的秩至多 $149+(68-33)=184$，原始小行列式也达到 184，所以 $H^9(F_{Sp})=495-184-310=1$。$SO(7)$ 的相应恒等式维数为 153、454、483、146；原始子式证明 $dI^8\ge152, dI^9\ge302, J\ge181$，后两项达到 $454-152$ 和 $146+(68-33)$ 的上界，因而 $H^9(F_{SO})=483-302-181=0$。

$Sp(3)$ 这个唯一的一喷注类不能被入射 $d_1$ 击中，因为上一切片的奇 $Y=9$ 上同调严格为零。出射 $d_1$ 的两喷注奇 $Y=9$ 靶也严格为零。仅剩出射 $d_2$ 靶 $(3,0,0;3,3)_8$，它的六个类全部由 Cartan 像检测；高阶微分的像在 Cartan 上为零（用标记乘法、闭的标量判别式和消去非零因子逐页证明），所以该箭头也为零。再高的阶由喷注次数排除。

**两喷注。** 普适 $(Y=7,8,9,10)$ 维数为 $(4216,4775,2554,510)$，稳定 $H^8,H^{10}$ 维数分别是 136 和 4。$I^7=0$，两套 $(I^8,I^9,I^{10})$ 维数分别为 $(92,136,53)$ 与 $(97,142,55)$。$I^8$ 上的 $(Q_0,\rho_4)$ 分别达到满列秩 92 与 97，故有限 $H^7=0$。$SO(7)$ 的 $I^9\to I^{10}$ 原始秩下界 50，$I^{10}$ 上秩四 Cartan 像秩 3，故这个秩正好是 $53-3=50$。$Sp(3)$ 顶层有限出射原始秩 454；普适对应秩为 $510-4=506$，差 52，且 $I^9\to I^{10}$ 原始子式达到 52。两者奇 $H^9$ 因而均为零。长正合列给出
\[
\dim H^8(F_G)=136-\dim I^8_G+\dim I^9_G-\operatorname{rank}Q_0|_{I^9_G},
\]
即 130 与 129；两边都有 129 个 Cartan 可检测的闭乘积。$SO(7)$ 的额外方向是首次经典差异所在的 $E+J_L=9$ 的已知低阶 lifting 配对经与 $Q$ 对易的超共形生成元升到这一荷数所得的出射 $d_1\ne0$ 源。它移除一个方向。剩余的 129 个闭乘积既有全阶闭代表，又不能成为任何高阶微分的像。

**三喷注。** 中央维数 476，两相邻原始子式秩为 267 与 209，两个群均饱和。因此这一中央切片为空；不要与一喷注 $d_2$ 的不同物理荷数靶 $(3,0,0;3,3)_8$ 混淆。
