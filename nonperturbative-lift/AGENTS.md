# Working in non perturbative lift

1. **Find the claim before opening the archive.** Run `python3 -B tools/project.py claims <keywords>` or `claims --status open`; then `show <id> --json`. Read `sector`, `coefficient_ring`, `hypotheses`, `statement`, and `limits` together. `depends_on` lists other claim IDs. For an unfamiliar theory, open the [review](research/03-review.md); use the [chapter index](research/README.md) to avoid loading the whole manuscript.
2. **Check the warrant.** Follow the exact `derivation` anchor, then `evidence`. For `archive:` paths use `extract <member> <new-file>` after `tools/project.py`; extraction verifies the digest and refuses overwrite. A saved certificate, a newly executed calculation, and an external theorem have different evidential uses. [Verification](verification/README.md) explains each and links the four separately distributed polynomials.
3. **Retain the source conventions.** In the $SU(2)$ product files the stored degree-four class has the opposite sign to the article's $C_4$. The source loop parameter and the stored rational differential also have an explicit conversion; see [product conventions](research/04-complex-and-products.md) and [kernel normalization](research/24-product-kernels.md). State whether you work in formal series, at a fixed nonzero parameter, or after inverting a field. A diagonal restriction tests an obstruction; a zero restricted result still needs a full-field proof.
4. **Continue one named problem.** `show <id> --next` reads just that task from [OPEN_PROBLEMS.md](OPEN_PROBLEMS.md): the next equation, inputs and completion test. Run `replay --list` first. Start with the portable entry in [the catalog](checks/catalog.json); historical scripts may write on import or rely on intermediate files that are absent. Keep new calculations outside `sources/` and `evidence/`; these are pinned records.
5. **Record changes where the next agent will find them.** Keep claim IDs and explicit derivation anchors stable. For a stronger assertion, record the proof or full residual and its hypotheses, add or update the replay when applicable, and revise the claim's status and limits. Leave a failed bounded search open. For an intentional manuscript edit, review the diff and update only the affected chapter digest and statistics in [sections.json](research/sections.json); preserve the historical pre-split source digest. Run `python3 -B tools/project.py verify` and any affected replays. No private session state, absolute machine paths, or live reader is required for this workflow.
