# Public verification tier

This is the designated inexpensive tier for A08. It checks the unchanged
published coefficient dual, the complete independent orthogonal return
identity, the coupled-equation and lossless-packing controls, and the complete
new SU(3) generator certificate. Version two adds the complete accepted ledger,
the USp(4) physical block and its first quantum-order small channel, and the
permitted F4 direct-factor identities. A real copied input is corrupted and
must be rejected. Every input manifest, command, exit status and output hash
is recorded. The complete runner executes sixteen checks.

From a **clean Linux checkout**, with Python 3.12:

```sh
python -m pip install -r research-roadmap/verification/requirements.txt
python -B research-roadmap/verification/run.py --output /tmp/public-verification-receipt
```

The runner refuses a dirty checkout unless explicitly invoked in development
mode. Development mode cannot produce a clean-checkout receipt. Historical
controls that write beside their source run from unchanged temporary copies.
No private paths, cluster credentials or scheduler impersonation are used.
No projection routine is invoked by these entry points.

## What is rebuilt

| Entry point | Exact scope |
|---|---|
| Roadmap validator | Weights, dependencies, pins and generated documentation |
| Sp(3) coefficient dual | The published candidate's exact pairing one; inherited closure and completeness |
| SO(11) global return | All 1000 marker monomials and the independent coefficient-operator bridge |
| Coupled equations | Complete small control, all homogeneous directions and restart |
| Map packing | All control entries, missing-row rejection and a corrupted matrix entry |
| SU(3) generator certificate | Complete rational ranks, relations and duals; archived frame entries reused |
| SU(3) independent polynomial check | The whole printed derivative and all 1588 native residual coordinates |
| Claim ledger | Exact assembly of all reviewed bytes; authentication of the strict complete-audit receipt, 247 claim records, 12 release texts and expanded coverage |
| USp(4) physical block | Every finite null relation and harmonic equation; all 4761 entries of the complete physical form; independent normalization and Wick controls |
| USp(4) small quantum channel | Complete three-dimensional source, two-dimensional target, exact physical forms and normalized first quantum coefficient |
| F4 direct-factor proof | 100 pinned public blobs, complete rational product equations and 60-column bilinear identities; authentication of the 150850-entry native extension |

The corresponding expensive source rebuild is separately callable:

```sh
python -B algorithms/su3_generator_20261124/reproduce.py /tmp/su3-generator-rebuild
```

Historical production replays remain documented in their original bundles.
This inexpensive tier does not claim to reconstruct the unverified remaining
G2 source-minor entries, the dense SU(3) production correction maps, or the
complete F4 source minor. The F4 second-map conclusion combines freshly
checked direct-factor identities with the explicitly attributed published
complete-source rank theorem. The large USp(4) Wick matrices are authenticated
and all their defining finite/harmonic equations are checked, but their full
Wick generation is not repeated by this inexpensive tier.

The ledger check authenticates the unchanged strict semantic/reference audit
and all its named data. It is not labelled a fresh review or a fresh validation
of every historical Git reference. With all pinned public Git objects present,
the full reference audit is separately callable:

```sh
python -B research-roadmap/claim-ledger/check.py --negative-controls --require-complete --receipt /tmp/claim-ledger-check.json
```

A08 additionally depends on completion of A07; introducing this runner alone
earns no point. The initial receipt records `passed: false` and is replaced by
a passing receipt only after every required check and the final clean-state
check succeeds.
